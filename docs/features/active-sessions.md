# 活跃会话区

默认：开

在「工作区」列表上方新增一块「活跃会话」：

- 列出最近 n 小时内活跃的会话，按最后活动时间倒序，最后活跃的在最上面；
- 行样式与工作区里的会话行一致：标题、运行状态点、「…」菜单与右键菜单都复用内置会话行的动作；行高比工作区列表略大，标题与第二行小字之间留出间距，不拥挤；
- 第二行用小字显示所属工作区与相对时间；点击行打开该会话，悬停显示完整标题、路径与状态；
- 行符合内置会话行的 DOM 契约，安装 `dsh-plugin-busy-workspace` 时同样被它的注意力规则着色：待处理、运行中、已完成（未读）、已中断，并显示子智能体胶囊；该兼容可在设置页用「兼容 busy-workspace」开关单独关闭（默认开启）；
- 待审批、计划待审、待回答会直接显示在第二行；
- 所在工作区已归档、未开始的空白会话与子代理会话不进入列表；
- n 小时内完全没有活跃会话时，改为显示最近 5 个（数量可设置）会话，并在列表上方注明；
- 活跃会话区可折叠，默认展开。

侧栏收成 rail 图标态（56px）时这一区换成图标形态：标题行显示图标、不显示折叠三角，区块固定展开不可收起；每行只留会话标题首字并带一个省略号（14px），完整标题留在原生 tooltip 与悬停卡片里，点击照常打开会话。安装 `dsh-plugin-busy-workspace` 时它的行着色、左侧色条与状态点在这一形态下照旧生效。这一区所在的 rail 里，下方「工作区」保持原生行为，不折叠、不加折叠箭头；宽栏布局不受影响。

同时把内置的「工作区」列表折成一行标题：点标题展开或收起，默认折叠；点标题里的搜索、视图、添加工作区按钮会自动展开。折叠状态不持久化，刷新后回到默认。关闭该功能后恢复原生侧栏。

默认窗口为 12 小时，可在设置页调整（1–168 小时）与兜底数量（1–50 个）。

## Dashboard

「活跃会话」标题右侧的网格按钮打开 Dashboard 页面，不单独占功能开关，跟随「活跃会话区」总开关：

- Dashboard 是覆盖主对话列的独立页面：从原生会话头部覆盖到主输入框顶部；上半是 m × n 的会话网格，下半只保留原生输入框（模型选择、余额、发送/排队等既有控件仍在），不重复显示当前会话的消息或 transcript；
- 打开时侧栏的活跃会话行与工作区区域（含标题与搜索）隐藏，保留顶部图标、本机标识与账号区域；原生会话头部被覆盖时也不可聚焦；关闭后完整恢复；
- 网格默认 2 × 2，行列各可在设置页调为 1–4；按活跃会话顺序从左到右、从上到下填充，会话不足时留空；
- 每格标题显示会话标题，状态点区分运行中、待响应、已完成未读与空闲；当前下方输入对应的会话标「当前」；
- 格内直接复用 DSH 原生 Chat 渲染该会话的真实对话与流式进展，不另做摘要；格内输入框隐藏，只读预览，加载历史时自动追到最新；
- 单击格子：高亮该格，把下方输入框切到该会话，并等主会话切换完成后再聚焦主输入框；点击格内链接或工具按钮、有文本选区时不抢焦点；
- 待审批、待回答、计划待审的会话格用醒目边框与状态徽标提示，但不会自动抢走输入目标，点击后才接管；
- 双击格子标题：关闭 Dashboard，把该会话作为普通全屏会话打开；
- 输入草稿由 DSH 按会话保存：切换前先让当前输入框失焦，切回时恢复；输入框占位与发送按钮状态随实际文本更新；
- 右上角关闭按钮或再次点击侧栏网格按钮退出；刷新页面后回到关闭状态；
- Dashboard 用固定覆盖层承载，切换会话不重建网格、不重载格子；关闭后普通会话视图保持原样；
- 历史特别大的会话在初次打开时可能短暂显示「载入历史…」，这是宿主加载会话历史的原生状态。
