# 备忘录

右侧栏按会话记录 Agent 产生的提醒与待办，供你在对话结束后逐条核对。

- 条目按「用户每一轮输入的提示词」分组，组头显示「第 N 轮」与提示词预览，悬停看全文。
- 每条都能勾选完成；勾选后原地划线保留，不隐藏。
- 一轮里的条目全部勾完后，这一轮自动收起，只留一行「第 N 轮 + 提示词预览」；点这一行可重新展开，取消勾选后再次自动展开。
- 已完成的条目无论原本几行，都压缩成一行显示；其中 callout 条目带 `[注意]`、`[警告]` 这类前缀，与普通提醒区分。
- 待办可以多层级：子任务还能继续嵌套（`memo_add` 与自动提取最多 3 层，存储最多 5 层），按层级缩进显示；父节点状态由整棵子树推导（所有叶子完成才算完成），点父节点会把整棵子树标记完成，不会反向取消已完成项。
- 双击条目按设置执行（默认把文字追加到输入框新行，保留原有草稿）。
- 条目菜单（行尾 `⋯` 或右键）：追加到输入框、复制文本、标记完成/取消完成。
- 会话标题栏的计数按钮显示「备忘 2/7」，全部完成显示「备忘 ✓」，会话没有条目时不显示。
- 打开入口：右侧栏起始页的「备忘录」卡片、`Ctrl+Alt+M`（mac `Cmd+Alt+M`，可在快捷键设置里改）、会话标题旁的「备忘 2/7」按钮（再点一次关闭面板）。
- 面板内容区独立滚动（细滚动条，跟随主题色），顶部工具栏与设置抽屉固定可见；每次打开面板时视口停在第一个未全部完成的轮次，之后的勾选不会改变阅读位置。
- 面板顶部工具栏：展开全部、收起全部、收起已完成、刷新，以及齿轮设置；齿轮在工具栏下方展开内联抽屉，可就地切换自动提取、callout 收录与双击动作。宿主没有向面板暴露「跳到指定设置分节」的调用面，所以抽屉是面板内的唯一设置入口；完整配置仍在「设置 → NEVSTOP-LAB」。

## 写入与分组

Agent 通过 `memo_add` 工具写入，一次可传多条，子代理写入的条目归到根会话。轮次与提示词来自会话日志的只读扫描（最近的 `turn/start` 与其后首条用户消息）；读不到时归入「未识别轮次」。同一轮内按文本去重，重复条目跳过。

回复里的 GitHub 风格 callout（`> [!NOTE]`、`> [!WARNING]` 等）由宿主在回合结束时自动收录，条目按 callout 类型着色显示；不依赖 Agent 主动调用工具，可用设置里的「自动收录 callout」关闭。

条目文本支持 Markdown：**粗体**、`行内代码`、链接、无序/有序列表、引用块，以及 `> [!NOTE]` 这类 callout 块。callout 的强调色取自 DSH 主题 token（brand / success / warn / error，`important` 为 brand 与 error 的混合），与 Chat 里的 GitHub 告警保持同一套配色；`memo_add` 也可以直接指定 `callout` 类型。

提示词注入让 Agent 知道何时记录 callout 之外的提醒：需要用户记住的限制、留给用户的后续动作；日常进度不记录。注入开关关闭后，工具与提示词都不再出现在模型侧。

每轮结束还会跑一次**轻量提取**：只把「本轮用户提示 + 最终回复」交给一次小模型请求，由它判断哪些内容需要记住（含 callout、待确认项、后续动作），结果按当前轮写入。提取结果按文中首次出现的顺序排列；当每条文本都能在回复里定位到原文时，宿主会再按位置校正一次顺序。它不读历史、不建会话、不写会话日志；请求失败或没有可用模型时，回退到 callout 规则提取。

## 数据

- 位置：`%USERPROFILE%\.dsh\plugin-data\dsh-nevstop-lab-flavor\memo\<sessionId>.json`（`DSH_HOME` 生效时跟随该目录）。
- 与会话日志完全分离：文件损坏、被删除或插件被停用，只影响面板内容，会话照常加载。
- 分叉会话会复制来源会话的备忘录（仅浏览器侧发起的 fork）；归档保留数据。
- 写入使用临时文件加改名，读取时逐字段校验，坏条目丢弃、好条目照常显示。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `features.memo` | 开 | 功能总开关；关闭后不注册工具、不注入提示词、不出现面板与入口 |
| `memo.injectPrompt` | 开 | 是否向 Agent 注入写入提示词 |
| `memo.autoCallouts` | 开 | 回合结束时自动把回复里的 callout 收录为条目 |
| `memo.autoExtract` | 开 | 回合结束时用一次轻量模型请求提取提醒；关闭后只保留 callout 规则 |
| `memo.extractProvider` / `memo.extractModel` | 空 | 提取用的模型，设置页为供应商/模型下拉（含「跟随默认模型」）；留空跟随当前默认模型 |
| `memo.extractPrompt` | 空 | 提取指令；留空使用内置提示词（设置页可查看内置原文） |
| `memo.doubleClick` | `menu` | 双击动作：`append` 追加到输入框、`menu` 打开条目菜单、`copy` 复制文本、`none` 无操作 |

## 降级

右侧栏标签页注册（`sidebarRightTabs`）、上下文菜单（`contextMenus`）、快捷键（`shortcuts`）任一不可用时，对应入口单独缺席，其余功能照常。面板渲染异常只让面板内容区显示错误文案，不影响会话与其它功能。
