# 备忘录

右侧栏按会话记录 Agent 产生的提醒与待办，供你在对话结束后逐条核对。

- 条目按「用户每一轮输入的提示词」分组，组头显示「第 N 轮」与提示词预览，悬停看全文。
- 点组头的「第 N 轮」胶囊，Chat 历史滚到该轮对话并短暂高亮落点；该轮还没加载进 Chat 时，按 Chat 自己的「加载更早」逐页翻历史直到出现该轮，仍找不到会提示。组头其余区域点一下折叠/展开这一轮。
- 每条都能勾选完成；勾选后原地划线保留，不隐藏。
- 一轮里的条目全部勾完后，这一轮自动收起，只留一行「第 N 轮 + 提示词预览」；点这一行可重新展开，取消勾选后再次自动展开。
- 勾掉最后一条未完成事项后，面板自动收起（当前标签是别的面板时不打断）；设置页的备忘录卡片与面板抽屉里都能关掉这个行为，关掉后勾完最后一条面板保持打开。
- 已完成的条目无论原本几行，都压缩成一行显示；其中 callout 条目带 `[注意]`、`[警告]` 这类前缀，与普通提醒区分。
- 待办可以多层级：子任务还能继续嵌套（`memo_add` 与自动提取最多 3 层，存储最多 5 层），按层级缩进显示；父节点状态由整棵子树推导（所有叶子完成才算完成），点父节点是整组切换：还有未完成就把整组标记完成，整组已完成则全部取消。
- 双击条目按设置执行（默认把文字追加到输入框新行，保留原有草稿）。
- 条目菜单（行尾 `⋯` 或右键）：追加到输入框、复制文本、标记完成/取消完成。
- 会话标题栏的计数按钮显示「备忘 2/7」，全部完成显示「备忘 ✓」，会话没有条目时不显示。
- 打开入口：右侧栏起始页的「备忘录」卡片、`Ctrl+Alt+M`（mac `Cmd+Alt+M`，可在快捷键设置里改）、会话标题旁的「备忘 2/7」按钮（再点一次关闭面板）。
- 面板内容区独立滚动（细滚动条，跟随主题色），顶部工具栏与设置抽屉固定可见；每次打开面板时视口停在第一个未全部完成的轮次，之后的勾选不会改变阅读位置。
- 面板顶部工具栏：展开全部、收起全部、收起已完成、刷新，以及齿轮设置；齿轮在工具栏下方展开内联抽屉，备忘录的每个分项配置都能就地改（注入提示词、自动提取、callout 与清单收录、提取供应商/模型、提取提示词、最后一条完成后是否关闭面板、双击动作）。宿主没有向面板暴露「跳到指定设置分节」的调用面，所以抽屉是面板内的设置入口；功能总开关仍在「设置 → NEVSTOP-LAB」（关掉后入口与面板一起消失，无法从面板里打开）。

## 写入与分组

Agent 通过 `memo_add` 工具写入，一次可传多条，子代理写入的条目归到根会话。轮次与提示词来自会话日志的只读扫描（最近的 `turn/start` 与其后首条用户消息）；读不到时归入「未识别轮次」。

同一轮内按内容去重，重复条目跳过：换措辞、加解释、把整条拆成子项都算同一条，只留信息更全的那条；带子任务的写法替换同义的平铺写法时，保留原来的条目、勾选状态与 callout 类型。两边都用引号或代码记号点名了不同对象的（`「启动网关」` 与 `「打开网页视图」`、`run.jsonl` 与 `events.jsonl`）不算同一条；没有共同点名对象的两条要几乎逐字相同才算同一条，避免把只差一个关键词的两条并掉。

Agent 还能用 `memo_update` 勾掉已经处理完的条目：按内容相似匹配，同一文本跨轮重复出现的会一次全部勾掉，也可以传 `done: false` 撤销；短引一句会命中所有相似条目，想只勾一条就引原句。不传 `items` 时它返回当前未完成清单，Agent 先看清单再决定勾哪几条。它只认叶子条目（带子任务的父项要传子任务文本），只改状态、不新增条目，父项状态照样由子树推导。未完成清单按实际条数全列出，每条给短引；未匹配文本最多回 8 条并另给总数。

排查用 `memo_read`：只读返回条目明细（每条 id、文本、完成状态、层级）与提取日志尾部。默认回前 40 行，`limit` 可调到 400（`0` 表示只要计数），可按 `turn` 与 `unfinishedOnly` 筛选，`rowTotal` 给筛选后的总数；每条文本与每行日志都截成短引，日志尾部最多 200 行。据此区分「模型没返回」「供应商拒绝」「勾了哪几条」，它不写任何数据。

回复里的 GitHub 风格 callout（`> [!NOTE]`、`> [!WARNING]` 等）由宿主在回合结束时自动收录，条目按 callout 类型着色显示；不依赖 Agent 主动调用工具，可用设置里的「自动收录 callout」关闭。回复里的 callout 全部收录，不按张数截断。

标题行是「仍未覆盖 / 待验证 / 需要你手动补测 / 下一步」这类措辞、后面跟有序或无序列表时，这句标题成为一条父项，列表项是它的子任务（更深缩进的列表继续嵌套）；父项勾选会把整组子任务标记完成。这条规则与 callout 规则一起兜住「模型漏判」的情况。

条目文本支持 Markdown：**粗体**、`行内代码`、链接、无序/有序列表、引用块，以及 `> [!NOTE]` 这类 callout 块。callout 的强调色取自 DSH 主题 token（brand / success / warn / error，`important` 为 brand 与 error 的混合），与 Chat 里的 GitHub 告警保持同一套配色；`memo_add` 也可以直接指定 `callout` 类型。

提示词注入让 Agent 知道何时记录 callout 之外的提醒：需要用户记住的限制、留给用户的后续动作；日常进度不记录，并且写入前先查重——同一件事换个说法、或前面几轮已经记过的，只写一次且写最全的那条；这一轮处理掉了前面留下的待办时，用 `memo_update` 一并勾掉。注入开关关闭后，工具与提示词都不再出现在模型侧。

每轮结束还会跑一次**轻量提取**：把「本轮用户提示 + 最终回复 + 本会话当前未完成条目」交给一次小模型请求，由它判断哪些内容需要记住（含 callout、待确认项、后续动作、未覆盖清单），结果按当前轮写入。提取结果按文中首次出现的顺序排列；当每条文本都能在回复里定位到原文时，宿主会再按位置校正一次顺序。它不读历史、不建会话、不写会话日志。

同一次请求里，模型还能给出 `resolved`：本轮明确完成、验证通过、或已证明过时不再需要做的旧条目。宿主按**条目 id** 限定范围，只勾提取前就存在且文本能对上的未完成条目，因此不会把本轮新写入的同文本条目顺手勾掉；对不上的一律忽略，结果（含 `resolved 0/N`）写进 `_extract.log` 便于排查。这就是「每轮检查新待办时，也顺手回收前面已经处理掉的条目」，不依赖 Agent 主动调用 `memo_update`。

条目数量不设条数上限，改由提示词控制：提取指令要求「宁少勿多，一轮通常 0–3 条，能并进同一条就并」，这条只管清单之外的提醒，回复末尾的「还没做 / 下一步」清单仍逐条收录。本会话未完成清单完整喂给模型，清单过长时每条只留短引、整块保留首尾；回复超长时保留开头 60% 与结尾 40%（结尾的清单既是新条目来源，也是回收旧条目的依据），整份输入始终控制在可传长度内。

内置提取指令要求直接摘用回复里的原句、点名具体对象并用 `「」` 或反引号括起来、同一件事只输出一条——这样与 callout、清单规则的条目落在同一段原文上，去重才判得准；在设置里换成自定义指令后这些约束不再生效（含 `resolved` 的产出约定），需要自己写进指令，否则只剩合并阶段的近似判定。

模型结果与两条规则结果**合并**写入：模型条目在前，callout 与清单条目补充在后；同一件事换个说法只留一条，同一件事既有平铺条目又有带子任务的清单时保留带子任务的那条、把它挪到最早重复的位置，并继承被替换条目的 callout 类型。因此模型漏判、请求失败或没有可用模型时，回复里的卡片与未覆盖清单仍会进面板。诊断信息追加到 `memo/_extract.log`（失败原因、收录条数、模型原始输出的前 240 个字符）。

## 数据

- 位置：`%USERPROFILE%\.dsh\plugin-data\dsh-nevstop-lab-flavor\memo\<sessionId>.json`（`DSH_HOME` 生效时跟随该目录）。
- 与会话日志完全分离：文件损坏、被删除或插件被停用，只影响面板内容，会话照常加载。
- 分叉会话会复制来源会话的备忘录（仅浏览器侧发起的 fork）；归档保留数据。
- 写入使用临时文件加改名，读取时逐字段校验，坏条目丢弃、好条目照常显示。
- 存储侧只保留结构性防护：单轮超过 200 条只保留最近 200 条、单条 text 超过 400 字截断、嵌套超过 5 层截断、轮次分组超过 400 组只保留最近的。这些不限制模型与规则能产出多少条目——产出量由提示词控制。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `features.memo` | 开 | 功能总开关；关闭后不注册工具、不注入提示词、不出现面板与入口 |
| `memo.injectPrompt` | 开 | 是否向 Agent 注入写入提示词 |
| `memo.autoCallouts` | 开 | 回合结束时自动把回复里的 callout 收录为条目 |
| `memo.autoExtract` | 开 | 回合结束时用一次轻量模型请求提取提醒，并回收 `resolved` 里已处理／已过时的旧条目；关闭后只保留 callout 规则 |
| `memo.extractProvider` / `memo.extractModel` | 空 | 提取用的模型，设置页为供应商/模型下拉（含「跟随默认模型」）；留空跟随当前默认模型 |
| `memo.extractPrompt` | 空 | 提取指令；文本框直接显示当前生效的指令（空时就是内置的中文提示词），可原地修改，清空即恢复内置；改成自定义指令后，内置的「摘用原句、点名对象、只输出一条」约束不再生效 |
| `memo.autoCloseDone` | 开 | 勾掉最后一条未完成事项后自动收起面板；关闭后面板保持打开 |
| `memo.doubleClick` | `menu` | 双击动作：`append` 追加到输入框、`menu` 打开条目菜单、`copy` 复制文本、`none` 无操作 |

## 降级

右侧栏标签页注册（`sidebarRightTabs`）、上下文菜单（`contextMenus`）、快捷键（`shortcuts`）任一不可用时，对应入口单独缺席，其余功能照常。面板渲染异常只让面板内容区显示错误文案，不影响会话与其它功能。
