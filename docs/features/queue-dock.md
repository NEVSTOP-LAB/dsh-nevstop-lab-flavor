# 排队消息默认展开

运行中排队的消息在输入框上方以面板列出。DSH 原生只显示计数头部，内容默认折叠；打开本功能后，面板第一次出现时自动展开，与截图里的样子一致。

- 面板在每次出现时展开一次；之后想收起就收起，插件不再插手。
- 单条排队消息没有计数头部，列表本来就可见，不受影响。
- 面板头部在编辑或处理中处于禁用态时跳过，等它恢复可用后再展开。
- 关闭开关：回到 DSH 原生行为（折叠计数条），手动展开/收起照旧可用。
- 配置键：`features.queueDock`，默认开。

实现只认宿主面板上的 `data-queue-dock` 与头部按钮的 `aria-expanded`：结构不匹配时什么都不做，最坏是「不生效」，不会挡住排队、编辑或插话。
