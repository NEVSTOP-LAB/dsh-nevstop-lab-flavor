# 设置页

入口：**设置 → NEVSTOP-LAB**。

- 每个功能一张卡片：图标、名称、一句话说明、齿轮与开关；
- 详细配置默认收起：点卡片右侧的齿轮展开该项配置，再次点击收起；
- 同一时间只展开一张卡片，展开另一张时上一张自动收起；
- 关闭某项功能时，它的齿轮与已展开的配置一起收起；
- 「恢复默认」一次性还原所有功能开关与键位；
- 「活跃会话区」卡片里还能调整活跃窗口、兜底数量，以及 Dashboard 的行数、列数（1–4，默认 2 × 2）与显示比例（50–100，默认 90）；Dashboard 页头的比例下拉也可直接调整；
- 「备忘录」卡片里可以关闭向 Agent 注入提示词、关闭 callout 与未覆盖清单的自动收录、关闭轻量模型提取，并用供应商/模型下拉选择提取模型（默认「跟随默认模型」），配置提示词（文本框直接显示当前生效的指令，默认就是内置中文文本，可原地改；清空即恢复内置），选择勾完最后一条后是否自动收起面板（默认开），以及选择双击条目的动作（追加到输入框、打开条目菜单、复制文本、无操作）；
- 窄屏（≤640px）下配置行改为「标签在上、控件占满一行」，避免标签被挤成竖排单字；
- 默认模型监听只响应默认模型开关、供应商、模型与推理强度的变化；调整 Dashboard 比例/行列等无关配置不会重置已手动选择的模型；
- 设置页表头（「NEVSTOP-LAB」标题右侧）放一行版本与更新：显示当前安装版本（读宿主插件清单）；点「检查更新」拉取 GitHub tag 并比较，把查到的最新版本写入插件配置；之后打开设置页直接用保存的版本提示「有新版 vX」并给出「更新」按钮，不自动联网查询；点击「更新」经宿主插件管理接口按 git tag 安装，完成后刷新页面生效；状态（检查中/已是最新/检查失败/已安装）压在同一行文本里，失败原因放在该行 tooltip；宿主未提供安装接口时只显示检查结果。
- 修改即时生效并持久化，界面跟随亮/暗色主题。
