# 设置页

入口：**设置 → NEVSTOP-LAB**。

- 每个功能一张卡片：图标、名称、一句话说明、齿轮与开关；
- 详细配置默认收起：点卡片右侧的齿轮展开该项配置，再次点击收起；
- 同一时间只展开一张卡片，展开另一张时上一张自动收起；
- 关闭某项功能时，它的齿轮与已展开的配置一起收起；
- 「恢复默认」一次性还原所有功能开关与键位；
- 「活跃会话区」卡片里还能调整活跃窗口、兜底数量，以及 Dashboard 的行数、列数（1–4，默认 2 × 2）与显示比例（50–100，默认 90）；Dashboard 页头的比例下拉也可直接调整；
- 修改即时生效并持久化，界面跟随亮/暗色主题。
